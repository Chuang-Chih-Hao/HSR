# 🚄 HSR QUEST — 高鐵勇者冒險

從**左營**出發，與朋友雙人連線合作打怪，升級後一路前往**南港**！適合小朋友操作的網頁冒險遊戲。

> 本作品為幻想遊戲，非台灣高鐵官方服務。直達快車是遊戲設計，**不代表真實列車班次或停靠資訊**。

## 遊戲特色

- **雙人即時連線**：房主建立 6 碼房間代碼，朋友可從其他裝置加入。同步怪物 HP、隊友 HP、經驗值、金幣與戰鬥紀錄。
- **兩種路線**：直達快車（4 場高強度戰鬥）或站站停靠（經過 11 個關卡）。
- **打怪升級**：普通攻擊獲得能量，使用必殺技或為隊友補血。擊敗怪物可獲得經驗值與金幣，升級提升生命值與傷害。
- **團隊合作**：怪物定期反擊，雙人 HP 都歸零即挑戰失敗。通關可重新開始。
- **自適應版面**：桌機、平板及手機均可操作。鍵盤 A／S／D 分別是攻擊／必殺技／補血。

## 遊戲操作

1. 玩家一輸入暱稱並點「建立新房間」。
2. 玩家二在其他瀏覽器輸入 6 碼代碼，或點擊房主分享的邀請網址加入。
3. 房主選擇直達快車或站站停靠，兩位玩家到齊後按「開始冒險」。
4. 戰鬥期間使用：**普通攻擊**（+1 能量）、**必殺技**（消耗 3 能量）、**團隊補血**（消耗 2 能量）。
5. 擊敗每一關怪物，最終挑戰南港終點魔王。通關或失敗後房主可重新開始。

## 本機執行

需 Node.js 20 以上：

```bash
npm install
npm start
```

瀏覽 `http://localhost:3000`。同一台電腦可使用兩個瀏覽器分頁測試；真正跨裝置連線時，兩台裝置都需能連至伺服器網址。

```bash
npm test
```

## Render 部署

使用 **Web Service**，不是 Static Site（此遊戲需要 WebSocket 伺服器）：

| 設定 | 值 |
|---|---|
| Repository | `Chuang-Chih-Hao/HSR` |
| Runtime | Node |
| Branch | `main` |
| Region | Singapore（推薦） |
| Build Command | `npm install --omit=dev` |
| Start Command | `npm start` |
| Health Check Path | `/health` |
| Auto Deploy | Enabled |

可使用專案附帶的 `render.yaml` 建立 Blueprint。Render 會設定 `PORT` 環境變數，伺服器會自動使用它。

**架構：** Express 提供靜態網頁；Socket.IO 處理房間、戰鬥與狀態同步。遊戲狀態只保存在 Node.js 記憶體中；服務重啟、休眠後喚醒、或部署更新會清空房間。請使用**單一執行個體**，避免多實例間的狀態不一致。免費方案可能有休眠與喚醒等待。

## 已知限制 / 後續可擴充

- 最多兩位玩家一房；斷線後房間暫停，重新加入可以繼續，但玩家角色屬性會重設。房間沒有帳號密碼，不要用於競技或敏感資料。
- 無資料庫、永久存檔或排行榜；未來可增加持久化與驗證機制。
- 實際高鐵停靠站及時間請以台灣高鐵官方公告為準。
