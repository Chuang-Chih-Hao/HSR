# 🚄 HSR QUEST — 高鐵勇者冒險

從**左營**出發，與朋友雙人連線合作打怪，升級後一路前往**南港**！適合小朋友操作的網頁冒險遊戲。

> 本作品為幻想遊戲，非台灣高鐵官方服務。直達快車是遊戲設計，**不代表真實列車班次或停靠資訊**。

## 遊戲特色

- **雙人即時連線**：房主建立 6 碼房間代碼，朋友可從其他裝置加入。同步怪物 HP、隊友 HP、經驗值、金幣與戰鬥紀錄。
- **兩種路線**：直達快車（4 場高強度戰鬥）或站站停靠（經過 11 個關卡）。
- **打怪升級**：普通攻擊獲得能量，使用必殺技或為隊友補血。擊敗怪物可獲得經驗值與金幣，升級提升生命值與傷害。
- **團隊合作**：怪物定期反擊，雙人 HP 都歸零即挑戰失敗。通關可重新開始。
- **自適應版面**：桌機、平板及手機均可操作。鍵盤 A／S／D 分別是攻擊／必殺技／補血。

## 遊戲操作

1. 玩家一輸入暱稱並點「建立新房間」。
2. 玩家二在其他瀏覽器輸入 6 碼代碼，或點擊房主分享的邀請網址加入。
3. 房主選擇直達快車或站站停靠，兩位玩家到齊後按「開始冒險」。
4. 戰鬥期間使用：**普通攻擊**（+1 能量）、**必殺技**（消耗 3 能量）、**團隊補血**（消耗 2 能量）。
5. 擊敗每一關怪物，最終挑戰南港終點魔王。通關或失敗後房主可重新開始。

## 本機執行

需 Node.js 20 以上：

```bash
npm install
npm start
```

瀏覽 `http://localhost:3000`。同一台電腦可使用兩個瀏覽器分頁測試；真正跨裝置連線時，兩台裝置都需能連至伺服器網址。

```bash
npm test
```

## Render 部署

使用 **Web Service**，不是 Static Site（此遊戲需要 WebSocket 伺服器）：

| 設定 | 值 |
|---|---|
| Repository | `Chuang-Chih-Hao/HSR` |
| Runtime | Node |
| Branch | `main` |
| Region | Singapore（推薦） |
| Build Command | `npm install --omit=dev` |
| Start Command | `npm start` |
| Health Check Path | `/health` |
| Auto Deploy | Enabled |

可使用專案附帶的 `render.yaml` 建立 Blueprint。Render 會設定 `PORT` 環境變數，伺服器會自動使用它。

**架構：** Express 提供靜態網頁；Socket.IO 處理房間、戰鬥與狀態同步。遊戲狀態只保存在 Node.js 記憶體中；服務重啟、休眠後喚醒、或部署更新會清空房間。請使用**單一執行個體**，避免多實例間的狀態不一致。免費方案可能有休眠與喚醒等待。

## 已知限制 / 後續可擴充

- 最多兩位玩家一房；斷線後房間暫停，重新加入可以繼續，但玩家角色屬性會重設。房間沒有帳號密碼，不要用於競技或敏感資料。
- 無資料庫、永久存檔或排行榜；未來可增加持久化與驗證機制。
- 實際高鐵停靠站及時間請以台灣高鐵官方公告為準。

## 👩‍🏫 老師主持房間（不占學生名額）

首頁現在有三種入口：**老師建立教室**、**學生加入房間**、以及「兩位玩家自行建立房間（無老師）」舊模式。

1. **老師**填寫名稱，點「老師建立教室」，取得六碼房間代碼並分享給學生。老師身分**不占用兩位學生名額**，不會成為遊戲角色，也無法攻擊。
2. **兩名學生**各自輸入暱稱、同一組房間代碼，按「學生加入房間」。教室可以同時容納**一位老師＋兩位學生**。
3. 老師在準備室選擇「直達快車」或「站站停靠」，兩人到齊後按「開始冒險」。學生不能私自選路線或開局。
4. 戰鬥進行時，老師以觀戰身分看到兩位學生的生命值、等級、金幣、經驗值與戰鬥紀錄。通關或失敗後，老師可按「再次出發」。
5. 老師重新整理頁面時，瀏覽器會使用**僅儲存在該分頁 sessionStorage 的私密管理憑證**恢復房主權限。邀請學生的網址只包含房間代碼，**不會包含管理憑證**。若關閉分頁、清除工作階段資料或伺服器重啟，可能無法恢復主持權限，需重新開房。

老師離線期間，只要兩名學生仍在線，戰鬥不會暫停；但選路線、開始與重新開局必須等老師回來。教室房間保留到逾時清理（目前未活動時 2 小時），伺服器重啟仍會清空。若沒有老師，也可使用原本兩名玩家自行建房的模式。

## 🚄 3D 台灣高鐵模擬器（第二階段，2026-11）

除了原本的雙人合作打怪／老師主持教室，首頁新增 **「3D 高鐵模擬」** 入口：

- 網址：`/simulator.html`（與冒險遊戲共用 Render 網站）
- 程序化 **700T 風格** 8 節車廂、車頭曲面、車窗、橘色腰線、轉向架與集電弓。這是自製遊戲低多邊形模型，**不是官方 700T CAD 模型或照片等級精確模型**。
- 車站：左營、台南、嘉義、雲林、彰化、台中、苗栗、新竹、桃園、板橋、台北、南港，支持北上與南下。
- **站站停靠**或**直達快車**（直達站點僅為遊戲化範例，非實際時刻表）。
- 有模型的車站月台、月台遮雨棚、站名牌、列車到站減速／停站／開門／發車動畫。
- 3D 高架橋、電車線支柱、山地、樹木、城市與隧道，列車高速移動時周遭場景位移。
- 晴天、日落、夜間、雨天；追蹤、駕駛室、月台、自由旋轉視角。
- 繁體中文語音合成到站／發車廣播與音階提示；可開關音效、廣播，手動播放**集電弓風切合成效果音**。
- 目標速度 80–300 km/h、播放／暫停、重置、路線停靠進度。

### 使用方法

1. 在首頁點「🚄 3D 高鐵模擬」；不必建立多人房間也能試玩。
2. 選擇北上／南下、站站停靠／直達快車，以及天氣／鏡頭。
3. 設定目標速度，按「▶ 開始行駛」。列車按縮時遊戲節奏行駛，自動減速停靠、開門、廣播後繼續。
4. 點「🔊 音效：開」才會開啟環境音；不同瀏覽器的語音庫可能使國語廣播聲線略有差異。

3D 模擬使用 **Three.js ES Modules**，安裝於 Node.js 相依套件中由本站直接提供，使用者瀏覽器不需再向第三方 CDN 請求核心程式。瀏覽器必須支援 WebGL。模型與運行路徑採縮時、縮尺處理，**不代表真實距離、煞車距離、隧道氣動噪音或完整鐵道號誌系統**。集電弓產生氣動風切聲，不會在正常高鐵運行速度發生超音速音爆。3D 模擬器目前為**單人自由體驗**，原有雙人戰鬥／老師模式不受影響。
